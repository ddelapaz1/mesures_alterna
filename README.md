# Mesures en corrent altern

Laboratori virtual del mòdul 0962 (Sistemes de potència) per practicar mesures en circuits de corrent altern: RLC sèrie, RLC paral·lel i (R + L) en paral·lel amb C.

- Valors aleatoris (valors típics de taller) o introduïts a mà per a la font i per a cada element.
- Tria dos punts de l'esquema i mesura tensió, intensitat i potències activa, reactiva i aparent.
- Resultats en mòdul i fase, en forma binòmica i tal com els llegiria un multímetre (pantalla LCD de set segments amb autorang).
- Explicació pas a pas dels càlculs, diagrama fasorial, resum de tot el circuit i notes de teoria.

És un sol fitxer: obre `index.html` al navegador.
